What you get

PC feature parity, toggle every feature from plugin settings.

Expanded context menus Copy ID, Message Link, Raw message, Message JSON, Username, Channel/Guild Link and more on long-press.
Message & channel links Copy jump-to links for any message or channel, straight from the action sheet.
Avatar & Server Icon URL Grab profile and server icon URLs, plus username copy, without leaving the app.
Account & server dates Resolve when an account, server or channel was created and copy it as ISO time.
Author & role tags Show BOT and role tag chips next to message authors, like on desktop.
Forced Developer Mode Unlock developer mode so Copy ID is always available, no fiddling with settings.
Flux & DevTools inspection Scan stores, components and props from chat to debug Discord internals on the go.
Role icon editor Set an emoji role icon from mobile on boosted servers (level 2+) — pick a role, pick an emoji.

How to install

Install in Kettu

Takes about a minute.

1
Open Kettu & go to Plugins
Open the Kettu settings and open the Plugins tab.
2
Paste the plugin URL
Use the copy buttons above, then paste either https://article-hub-studio.github.io/kettu-plugin-same-more-boats/manifest.json (Same More Boats) or the Liquid Glass URL into the add-plugin box.
3
Enable & reload
Kettu fetches the manifest, loads index.js from the same host and activates the plugin. Toggle features from the plugin settings once it loads.
4
Debug from chat
Same More Boats registers a slash command: /smb status, /smb scan, /smb shape, /smb keys, /smb reset.
