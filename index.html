Install in Kettu

Takes about a minute.

Open Kettu & go to Plugins
Open the Kettu settings and open the Plugins tab.
Paste the plugin URL
Use the copy buttons above, then paste either https://article-hub-studio.github.io/kettu-plugin-same-more-boats/manifest.json (Same More Boats) or the Liquid Glass URL into the add-plugin box.
Enable & reload
Kettu fetches the manifest, loads index.js from the same host and activates the plugin. Toggle features from the plugin settings once it loads.
Debug from chat
Same More Boats registers a slash command: /smb status, /smb scan, /smb shape, /smb keys, /smb reset.
